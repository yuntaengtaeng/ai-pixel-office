# User Flow Modeling

사용자 목표에서 시작해 관찰 가능한 행동 순서와 완료 조건을 정의한다. 제품 내부 구현 순서가 아니라 사용자가
보는 흐름으로 작성한다. 범위 밖 흐름과 결정되지 않은 정책은 숨기지 말고 `open_questions`에 남긴다.
결과는 `templates/ux-handoff.yaml`과 `instructions/handoff-contract.md`를 따른다.
