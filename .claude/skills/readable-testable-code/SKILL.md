# Readable & Testable Code

원본은 [`ai-docs/skills/readable-testable-code/SKILL.md`](../../../ai-docs/skills/readable-testable-code/SKILL.md)다.
코드를 작성, 수정, 리팩터링, 리뷰하기 전에 원본 전체를 읽고 그 Agent Decision Rule 순서로 판단한다.

> **이 코드는 읽는 사람이 편한가?**
> **이 코드는 테스트하기 쉬운가?**

둘 중 하나라도 명확하게 "아니다"라면, 코드를 더 추가하기 전에 구조를 다시 검토한다.
