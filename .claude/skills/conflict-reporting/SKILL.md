# Conflict Reporting

충돌한 두 계약, 사용자 영향, 기술 영향과 가능한 최소 대안을 구분해 기록한다. downstream Agent가 자신의
편의를 위해 acceptance criteria나 UI behavior를 바꾸지 않는다. 되돌리기 어렵거나 영구 구조를 바꾸는
결정은 사용자 확인 및 canonical ADR 갱신 대상으로 표시한다.
