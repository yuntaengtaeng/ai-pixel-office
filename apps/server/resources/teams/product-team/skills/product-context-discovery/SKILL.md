# Product Context Discovery

관련 화면, Task 흐름, canonical 문서와 실제 구현을 확인한다. 사용자 인터뷰나 행동 데이터가 없으면 예상
사용자 요구를 사실로 표현하지 않고 가설과 확인 방법을 함께 남긴다. 이미 결정된 정책과 새로 결정해야 할
질문을 분리하며 코드 아키텍처는 결정하지 않는다.
