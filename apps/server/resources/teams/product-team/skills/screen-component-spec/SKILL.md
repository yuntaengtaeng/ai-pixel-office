# Screen and Component Spec

UX Handoff의 흐름과 상태를 빠뜨리지 않고 화면 및 component 구조로 대응시킨다. 고정 수치는 의도와 현재
design token 근거가 있을 때만 사용한다. desktop viewport, 긴 문구, keyboard focus와 reduced motion을
관련된 경우 명시한다. 결과는 `templates/ui-handoff.yaml`을 따른다.
