# Design System Discovery

작업 프로젝트의 design system 문서와 구현을 읽고 token -> component -> composition -> variant 확장 ->
신규 component 순서로 판단한다. 공용 token을 바꾸기 전 모든 소비처를 검색한다. 기존 체계가 UX 의도를
표현하지 못하면 억지로 재사용하지 말고 필요한 최소 확장과 영향을 기록한다.
