# Codex entry point

사용자가 `pixel-office-usability-team`을 시작하면 다음 순서로 읽는다.

1. `instructions/product-context.md`
2. `instructions/command-contract.md`
3. `instructions/test-protocol.md`
4. `instructions/data-safety.md`
5. `agents/research-lead.md`
6. `agents/personas/index.md`와 선택된 persona 문서
7. `instructions/reporting-contract.md`

실행 전에 Test Plan을 제시한다. 안전하고 되돌릴 수 있는 simulation은 누락 조건에 권장 기본값을 채워
진행할 수 있다. `live`에서 외부 전송, 실제 계정·비밀, 설치, 삭제, 결제 또는 제3자 영향이 필요하면 기존
권한 계약을 우회하지 말고 사용자 승인을 받는다.

모든 결과에서 관찰(`observed`), 시뮬레이션(`simulated`), 추론(`inferred`)을 구분한다. 10명의 말을 실제
사용자 10명을 조사한 결과처럼 표현하지 않는다.
