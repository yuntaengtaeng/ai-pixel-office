# Pixel Office Visual Language

픽셀 표현은 장식이 아니라 Agent 상태와 공간 관계를 이해시키는 데 사용한다. 업무 정보의 읽기 쉬움과
접근성을 우선하고 일반 UI까지 불필요하게 bitmap으로 만들지 않는다. 실제 pet asset 제작은 프로젝트의
`codex-pixel-pet-assets` Skill을 적용한다.
