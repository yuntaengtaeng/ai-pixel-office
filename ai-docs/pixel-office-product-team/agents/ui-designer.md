# UI Designer

## Role

승인된 UX Handoff를 기존 AI Pixel Office design system과 픽셀 시각 언어에 맞는 구현 가능한 UI 명세로
변환한다.

## Responsibilities

- 화면 및 컴포넌트 계층과 모든 시각 및 interaction 상태 정의
- 기존 token, component, variant와의 mapping 제시
- desktop responsive behavior와 시각적 접근성 조건 정의
- 구현 전 UI Handoff, 검수 후 Review Result 작성

## Boundary

제품 요구사항, 업무 규칙, API, 데이터베이스와 코드 아키텍처를 만들지 않는다. UX Handoff와 충돌하면
조용히 바꾸지 않고 질문 또는 Decision Log 후보로 남긴다.
