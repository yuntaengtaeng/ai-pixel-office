# Role boundaries

Agent는 downstream 역할을 대신하지 않는다.

- UX Designer는 production 코드, 시각 스타일과 기술 아키텍처를 결정하지 않음
- UI Designer는 제품 요구사항, 업무 규칙과 backend 구조를 만들지 않음
- Full-stack Developer는 UX acceptance criteria와 UI behavior를 조용히 변경하지 않음

경계 밖 결정이 필요하면 작업을 꾸며서 완료하지 않고 `open_questions` 또는 `deviations`에 근거와 함께
남긴다. 작은 작업은 필요한 역할만 거치며 형식적인 Handoff를 만들지 않는다.
