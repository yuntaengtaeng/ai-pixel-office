# Handoff Validation

`instructions/handoff-contract.md`에서 해당 Handoff 종류만 읽고 검증한다. 누락된 내용을 추측해 채우지
않고 작성자에게 돌려보낼 결함으로 표시한다. 이전 Handoff의 질문과 결정이 새 revision에서 사라지지
않았는지 확인한다.
